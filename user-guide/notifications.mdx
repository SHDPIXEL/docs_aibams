## Notification Settings

Manage your notifications from **Settings → Preferences → Notifications**.

---

## Notification Channels

You can choose how you receive notifications:

1. **In-App (Bell Icon)** — Always on. Shows an unread badge on the top navigation bar.
2. **Browser Push** — Requires browser permission. Delivers a native desktop notification even when AIBAMS is in the background.
3. **Email** — Sends notification digests or alerts to your primary email address.

<Tip>
  For the best experience, we recommend enabling **Browser Push** for important alerts and relying on the **In-App** bell for everything else.
</Tip>

## Event Categories

Customize alerts by application and event type:

### MailX Notifications

| Event | Recommendation |
|-------|----------------|
| New Email | Browser Push (for urgent inboxes) |
| VIP Sender | Browser Push & In-App |
| Daily Digest | Email (morning summary) |
| Sent Failure | Browser Push & In-App |

### FileX Notifications

| Event | Recommendation |
|-------|----------------|
| File Shared With Me | In-App & Email |
| Comment Mention | Browser Push & In-App |
| Upload Complete | In-App |
| Document Summarized | In-App |

### FusionX (AI) Notifications

| Event | Recommendation |
|-------|----------------|
| Long Task Complete | Browser Push & In-App |
| Automation Error | Browser Push & Email |
| Suggestion Ready | In-App |

### Team & System Notifications

| Event | Recommendation |
|-------|----------------|
| Team Mention | Browser Push & In-App |
| Role Changed | In-App & Email |
| Billing Issue | Browser Push & Email (Critical) |
| Security Alert | Browser Push & Email (Critical) |

## Quiet Hours

Prevent notification fatigue outside of your working hours.

1. **Settings → Preferences → Notifications → Quiet Hours**
2. Toggle **Enable Quiet Hours**
3. Set your schedule:
   - **Start time:** e.g., 6:00 PM
   - **End time:** e.g., 8:00 AM
   - **Days:** e.g., Saturday, Sunday

During Quiet Hours:
- Browser Push and Email notifications are paused
- In-App notifications still accumulate in the Notification Center
- **Critical Alerts** (security, billing failures) bypass Quiet Hours

---

## Muting Threads or Files

If a specific email thread or file discussion is generating too many notifications, you can mute it individually:

1. **MailX:** Open the email thread → Click **⋯** → **Mute Conversation**
2. **FileX:** Right-click the file → **Notifications** → **Mute File**

You will no longer receive push or email notifications for that specific item, but updates will still appear silently in the Notification Center.
