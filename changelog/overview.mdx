## Welcome to the AIBAMS Changelog

We push updates, bug fixes, and new features to AIBAMS continuously. Major feature releases and significant architectural changes are documented here.

Because AIBAMS is a unified platform running on FusionOS, updates are applied automatically. You never have to download or install updates manually.

---

## Release Cadence

- **Major Releases (v1.0, v2.0):** Significant architectural changes, entirely new core applications, or major UI overhauls. (Infrequent)
- **Minor Releases (v1.1, v1.2):** New features within existing apps, workflow improvements, and notable enhancements. (Monthly)
- **Patch Releases:** Bug fixes, security patches, and minor performance tweaks. These are deployed silently and continuously, and are generally not documented here unless they resolve a widely reported user-facing issue.

## Feedback & Feature Requests

The AIBAMS roadmap is heavily influenced by user feedback, especially from our Early Access cohort.

If you have a feature request or an idea to improve the platform:
1. Log into your AIBAMS dashboard.
2. Click the `?` Help icon in the top navigation bar.
3. Select **Submit Feedback**.

You can also email ideas directly to `product@aibams.com`.
